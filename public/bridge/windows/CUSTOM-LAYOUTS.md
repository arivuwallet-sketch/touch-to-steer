# Custom control layouts

Open **Settings > Custom layout editor**, then select **Edit gamepad layout** or **Edit steering layout**.

The separate full-screen editor lets you drag a control, drag its lower-right resize handle, or enter exact left/top/width/height percentages. Select hidden controls from the control list to show them again. Swap controls exchanges their positions and sizes while preserving their actions and visibility. Keyboard arrows move a selected preview control in 1% steps. Undo retains the last 30 edits.

**Save layout** applies the arrangement and saves it with this device's existing settings. **Cancel** discards the draft. **Reset selected control** and **Reset all** restore the editor's original measured arrangement; **Restore original layout** removes all custom overrides for that mode. Gamepad and steering layouts are independent. Settings remains accessible even if every control is hidden.

The preview uses labeled control boxes rather than operating the game. Held inputs are released before editing; analog/gyro and button writes are blocked during editing. Layout changes do not alter key mappings, ForceFlex/ForceAdapt curves, or the 1000 Hz scheduling target.

Positions and dimensions are stored as percentages and recalculated on screen resize. The wheel and its built-in buttons are a single movable unit; the separate pedals, nitro, handbrake, rate controls and telemetry can be arranged independently. Gamepad triggers, sticks, buttons and display are individually configurable. Mouse mode retains its existing layout. Layouts are stored locally, not synchronized between phones.
